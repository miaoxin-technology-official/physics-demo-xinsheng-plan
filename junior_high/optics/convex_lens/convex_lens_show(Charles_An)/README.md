# 凸透镜成像规律演示

初中物理 · 光学 · 凸透镜成像规律。拖动蜡烛改变物距，拖动红色焦点改变焦距，实时观察像的位置、大小、正倒和虚实，并显示三条特殊光线。

## 课件介绍

本课件演示凸透镜成像规律：左侧蜡烛为物，中间薄透镜，右侧按成像公式实时算出像的位置与大小。像用半透明蜡烛表示——实像倒立、画在透镜另一侧，虚像正立、用虚线轮廓画在物同侧，并标注“实像 / 虚像”。

顶部读数区同步给出物距 u、像距 v、焦距 f、放大率 |m|，以及一句话的成像结论（如“倒立、放大的实像（f < u < 2f）”），可以直接和课本上的规律表对照。

## 使用方法

1. 打开 `index.html`。
2. 左右拖动蜡烛，改变物距 u。
3. 左右拖动主光轴上的红色 F 或 F′ 标记，改变焦距 f（F、2F、F′、2F′ 的位置会同步变化）。
4. 也可以在顶部输入框直接输入物距和焦距，精确到 0.1 cm。
5. 点“自动演示”，物距会在 2.5 cm 到 24.5 cm 之间自动往返，适合课上做整体趋势演示；按钮变为“暂停”，再点一次即可停下。
6. 点“重置”，恢复到初始状态（物距 12 cm、焦距 7 cm，此时成倒立、放大的实像）。

## 交互说明

| 操作      | 位置                | 效果                                      |
| ------- | ----------------- | --------------------------------------- |
| 左右拖动    | 画布内的黄色蜡烛          | 改变物距 u，可调范围 2–26 cm                     |
| 左右拖动    | 主光轴上的红色 F / F′ 标记 | 改变焦距 f，可调范围 3–10 cm                     |
| 输入数值    | 顶部“物距 u”“焦距 f”输入框 | 精确设定参数，步长 0.1 cm，超出范围自动取边界值             |
| 点击按钮    | “自动演示”            | 物距自动往返扫描（2.5–24.5 cm，约 3.2 cm/s），再次点击暂停 |
| 点击按钮    | “重置”              | 恢复 u = 12 cm、f = 7 cm                   |
| 任意拖动或输入 | —                 | 自动演示立即暂停，交回手动控制                         |

数据范围与取值约定：

- 物距 u ∈ [2, 26] cm，焦距 f ∈ [3, 10] cm，均以 0.1 cm 为步长。
- 像距 v 用实数表示：v > 0 表示像在透镜右侧（实像），v < 0 表示像在透镜左侧（虚像），读数区用“−”号标出。
- |u − f| ≤ 0.05 cm 时判定为 u = f，提示“不成像”；|u − 2f| ≤ 0.05 cm 时判定为等大。
- 物距接近焦距时像距急剧变大，读数区中 |v| ≥ 1000 cm 时显示为“∞”。
- 放大率 |m| 取两位小数，显示为 |v / u|。

## 光路与图形含义

- **黑色实线 + 箭头**：光线，箭头指向光的传播方向。
- **灰色虚线**：成虚像时，折射光线的反向延长线。
- **红色短竖线**：焦点 F、2F（左侧）与 F′、2F′（右侧）。
- **半透明倒立蜡烛**：实像，能在光屏上承接。
- **虚线轮廓的正立蜡烛**：虚像，只能透过透镜用眼睛看到，光屏上接不到。
- **深色小圆点**：物点对应的像点位置。

课件画的是三条特殊光线：

1. 平行于主光轴射入的光线，折射后过另一侧焦点 F′；
2. 过光心的光线，传播方向不变；
3. 过焦点 F 射入的光线，折射后平行于主光轴。

其中第 3 条只有在该光线恰好能落在透镜有效口径内时才绘出，所以某些物距下画面上只显示两条光线，这是正常的。

## 成像规律对照表

| 物距 u       | 像距 v       | 像的性质     | 对应应用           |
| ---------- | ---------- | -------- | -------------- |
| u > 2f     | f < v < 2f | 倒立、缩小的实像 | 照相机、眼睛         |
| u = 2f     | v = 2f     | 倒立、等大的实像 | 测焦距（此时放大率恰为 1） |
| f < u < 2f | v > 2f     | 倒立、放大的实像 | 投影仪、幻灯机        |
| u = f      | 不成像        | 折射光平行射出  | 探照灯（光源在焦点）     |
| u < f      | 虚像，与物同侧    | 正立、放大的虚像 | 放大镜            |

> u < f 时像距为负值，表示像与物在透镜同侧，且像距大小大于物距，所以是放大的虚像。

一句话记忆：**一倍焦距分虚实，二倍焦距分大小；物近像远像变大。**

## 简化假设

- 透镜视为薄透镜，忽略厚度，以透镜中心为光心。
- 近轴光线近似，忽略球差、色差和衍射，光线用理想直线表示。
- 物体视为垂直于主光轴的线段（蜡烛），像高按几何比例缩放，不模拟真实亮度与光强衰减。
- 不模拟“移动光屏找清晰像”的过程，像的位置由成像公式 `1/f = 1/u + 1/v` 直接算出，所以画面里没有光屏控件。
- 物距、焦距限定在 2–26 cm、3–10 cm，避免像距过大、像跑到画面外而失去演示意义。
- 只画三条特殊光线，不画无数条光线组成的连续光锥。

## 已知限制

- 画面上没有光屏，不能像真实实验那样前后调屏找像；“像是否清晰”由公式保证，而不是由屏的位置决定。
- 当像在画面外或像高超出画面时，只在画布右上角提示“像在画面外 / 像高超出画面”，不再绘出像。
- 仅支持鼠标和触屏拖动，未提供键盘调节。
- 手机竖屏等窄屏下，焦点标签会缩小、间距变紧，建议横屏使用或用电脑投影。

## 教学提示

- **先定性、再定量**：先用三个区间（u > 2f、f < u < 2f、u < f）让学生说出像的性质，再用读数区核对。
- 用读数区验证 `1/f = 1/u + 1/v`，顺带讲清像距的符号约定：v > 0 在透镜右侧成实像，v < 0 在左侧成虚像。
- 把物距调到 2f 附近，让学生观察放大率 |m| 趋近于 1，理解“二倍焦距分大小”。
- 用“自动演示”走一遍完整变化过程，再停下来定点提问：
  - 物距从远处向焦点靠近时，像距和像的大小怎么变？
  - u = f 时为什么不成像？
  - u < f 时为什么光屏上接不到像，眼睛却能看见？
- 提醒学生区分“像离透镜远”和“像变大”：物越靠近焦点，像距越大、像也越大，两者是同向变化的。
