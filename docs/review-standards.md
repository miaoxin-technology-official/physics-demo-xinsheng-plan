# 课件 PR 审校标准

本文件是 AI 初审与人工审校共用的判定依据。AI 只读：只读 PR、只发评论，**不改代码、不 approve、不合并**。

## 等级定义

| 等级 | 名称 | 含义 | 处理方式 | AI 标记 |
| --- | --- | --- | --- | --- |
| **5** | 阻断 | 违反硬性规则，合并会坏库、打不开或构成侵权 | 必须修改，改完再审 | 🔴 |
| **4** | 重要 | 影响可用性或违反收录标准 | 建议改完再合并，维护者可要求修改 | 🟠 |
| **3** | 一般 | 规范、完整性或说明缺失 | 可合并，但应说明或后续补齐 | 🟡 |
| **2** | 提示 | 质量改进建议，不影响收录 | 可选 | 🔵 |
| **1** | 信息 | 记录性说明，无需动作 | 仅供参考 | ⚪ |

> 5 级以外的项都不阻断合并；**物理正确性与侵权认定以人工审校为准**，AI 只给线索。

---

## 5 级 · 阻断

| # | 检查项 | 判定依据 | 判定方式 |
| --- | --- | --- | --- |
| 5.1 | 目录层级错误 | 必须是 `<junior_high\|senior_high>/<学科>/<知识点>/<课件名>(<作者>)/` | 脚本 |
| 5.2 | 目录名不合规 | 英文括号，形如 `lever_demo(San_Zhang)`；不得有空格、中文括号、缺作者 | 脚本 |
| 5.3 | 三件套缺失 | 课件目录里必须有：至少 1 个 `.html`、`README.md`、`LICENSE` | 脚本 |
| 5.4 | 入口打不开 | HTML 为空文件，或引用的相对路径资源不存在 | 脚本 + 人工 |
| 5.5 | 提交禁止文件 | `.git/`、`node_modules/`、可执行文件、`Thumbs.db`、`__MACOSX` 等 | 脚本 |
| 5.6 | 许可不可用 | 无 LICENSE、识别不出许可证、写着 `All rights reserved` | 脚本 |
| 5.7 | 许可自相矛盾 | README 与 LICENSE 声明的许可证不一致 | 脚本 |
| 5.8 | 有使用门槛 | 登录、注册、付费、订阅、扫码关注才能用核心功能 | 脚本 + 人工 |
| 5.9 | 误改基础设施 | 改了 `.github/workflows/`、`scripts/`、根配置，而 PR 并不是维护性改动 | 脚本 |
| 5.10 | 恶意代码 | 外传数据、混淆 `eval`、自动跳转、挖矿脚本 | 人工 |
| 5.11 | 侵权素材 | 教材插图、商业课件、反编译自 Flash 的资源 | 人工（AI 仅标记线索） |

## 4 级 · 重要

| # | 检查项 | 判定依据 | 判定方式 |
| --- | --- | --- | --- |
| 4.1 | 没有交互 | 只有播放/静态图，没有拖动、调参、开关、暂停复位之一 | 脚本 + 人工 |
| 4.2 | 缺对应知识点 | README 里没有「对应知识点」一行（索引与分类依赖它） | 脚本 |
| 4.3 | 缺作者或版权 | README 没写作者，或没写版权说明 | 脚本 |
| 4.4 | 说明与课件不符 | README 声称的交互/现象，HTML 里实际没有 | AI + 人工 |
| 4.5 | 引用资源缺失 | 图片/音频路径在 PR 里找不到 | 脚本 |
| 4.6 | 夹带无关改动 | 一个 PR 混入多个课件，或混入与课件无关的大改动 | 脚本 + 人工 |
| 4.7 | 素材来源不明 | 用了外部图片/音频/字体，README 没写来源与许可 | AI + 人工 |
| 4.8 | AI 生成未声明 | 代码或文案明显由 AI 生成，但没有「已核对」说明 | AI |
| 4.9 | 年级缺失 | 没写适用年级；高中没写必修/选择性必修/选修 | 脚本 |

## 3 级 · 一般

| # | 检查项 | 判定依据 | 判定方式 |
| --- | --- | --- | --- |
| 3.1 | 手改 `index/` | 索引由 Action 自动重建，手改会被覆盖 | 脚本 |
| 3.2 | PR 标题格式 | 建议 `新增：<知识点> — <课件名> (<作者>)` | AI |
| 3.3 | 未写简化假设 | 有理想化处理却没注明（忽略摩擦、质点化等） | 脚本 |
| 3.4 | 外部依赖未说明 | 用了 CDN / 在线字体 / 在线 API，README 未提及 | 脚本 |
| 3.5 | 单文件过大 | 单个文件超过 5 MB | 脚本 |
| 3.6 | 新主题未说明 | 新建了学科或知识点目录，PR 描述没说 | 脚本 |
| 3.7 | README 过简 | 非中文，或只有标题没有正文 | AI |
| 3.8 | 缺使用方法 | 没写怎么操作、有哪些交互 | 脚本 |
| 3.9 | 兼容性未注明 | 用了较新 API，没写最低浏览器要求 | AI |

## 2 级 · 提示

| # | 检查项 | 说明 |
| --- | --- | --- |
| 2.1 | 物理表述疑点 | 公式、方向、单位、正负号、标注可能有问题，需教学审校确认 |
| 2.2 | 教学提示不完整 | 适用场景、易错点、课堂用法可再补充 |
| 2.3 | 可访问性 | 键盘可操作、对比度、色盲友好等 |
| 2.4 | 性能 | 大量 DOM、持续动画、未做节流 |
| 2.5 | 代码风格 | 命名、注释、结构可读性 |

## 1 级 · 信息

| # | 项目 | 说明 |
| --- | --- | --- |
| 1.1 | 断网可用性 | 本项目不要求，允许依赖 CDN |
| 1.2 | 技术栈 | 不限制框架与写法，能打开、开源即可 |
| 1.3 | 目录命名风格 | 建议小写英文 + 下划线，不强制 |
| 1.4 | 文件组织 | `assets/` 可选，不强制统一 |

## AI 初审输出约定

- 每条问题带等级、类别、文件路径、问题描述、修改建议；
- 5 级用 🔴、4 级 🟠、3 级 🟡、2 级 🔵、1 级 ⚪；
- 末尾汇总：`X 项阻断 / Y 项重要 / Z 项一般 / …`；
- 固定附一句：**AI 初审不替代人工审校，不会修改代码、不会 approve、不会合并**；
- 物理与版权问题一律标为「待人工」，AI 不下结论。

## 自动标签

PR-Agent 初审后，按本次发现的**最高等级**自动打一个标签：

| 最高等级 | 标签 | 含义 |
| --- | --- | --- |
| 5 | gent-reviewed-return | 有阻断项，退回修改 |
| 3-4 | gent-reviewed-warning | 有需要处理的问题，可改后合并 |
| 1-2 | gent-reviewed-pass | 只有提示/信息，可通过 |

标签由工作流自动增删，三个标签互斥，只会保留一个。

## 权限边界

| 能力 | AI 初审 |
| --- | --- |
| 读 PR 文件与描述 | ✅ |
| 发 / 更新一条评论 | ✅ |
| 修改代码、提交 | ❌ |
| approve / request changes | ❌ |
| 合并 PR | ❌ |

> 工作流只声明 `contents: read` 与 `pull-requests: write`，从权限上就不具备合并能力。
