# 许可证是什么？——写给物理老师看的说明

> 你做了一个物理动画，想放到这个仓库里给大家用。别人会问：我能不能拿去上课？能不能改？要不要给你钱？要不要写你的名字？
>
> **许可证，就是你对这些问题的一次性回答。** 写清楚一次，以后不用一个个解释。

---

## 一、先把词换成人话

「许可证」听起来很法律，其实就是**使用授权书**。

你可以把它想成借教具：

- 你把自制的教具借给同事，说「随便用，别弄坏就行」——这是一句话的口头许可；
- 如果你把它放在器材室，贴一张纸条：「欢迎使用，可自行改装，但请注明原制作者」——这张纸条就是「许可证」。

课件也一样：文件放在网上，别人不知道能拿它做什么。**LICENSE 文件就是那张纸条。**

> 没有纸条会怎样？别人不敢用——怕你以后找他要钱，怕学校检查时说不清。结果就是你的课件没人敢碰，白做了。

---

## 二、许可证到底管哪几件事

一份许可证通常回答四个问题：

1. **能不能用**：上课放给学生看，算不算允许？
2. **能不能改**：同事想改个参数、换个配色，行不行？
3. **要不要署名**：用的时候要不要写「原作者是张三」？
4. **能不能再分发**：能不能把你的课件再放到别的网站、别的学校共享？

不同的许可证，就是这四个问题的不同组合。

---

## 三、老师们最常用的三种

| 许可证 | 一句话理解 | 适合什么 |
| --- | --- | --- |
| **MIT** | 随便用、随便改、随便再发，**只要保留作者署名** | 代码型的 HTML/JS 课件 |
| **CC BY-SA 4.0** | 随便用、随便改，**要署名，而且改完的作品也要用同样的许可证共享** | 图片、音频等素材较多的课件 |
| **CC BY 4.0** | 随便用、随便改、可以闭源再发，**只要署名** | 希望被尽量广泛使用的内容 |

三者的共同点：**都允许学校免费使用，都不要求付费。**

区别主要在「改了之后要不要也开放」：

- MIT / CC BY 4.0：改了可以自己留着，不必公开；
- CC BY-SA 4.0：改了再发，必须也用 CC BY-SA 4.0（这叫「相同方式共享」）。

> 记不住也没关系：**这个仓库推荐 MIT 或 CC BY-SA 4.0，二选一即可。**

---

## 四、怎么选：问自己三个问题

1. **我做的主要是代码还是素材？**
   - 主要是 HTML/JS 代码 → 选 **MIT**
   - 主要是图片、音频、动画素材 → 选 **CC BY-SA 4.0**

2. **别人改了之后，我希望他也开放吗？**
   - 希望 → **CC BY-SA 4.0**
   - 无所谓 → **MIT**

3. **我介意别人拿去做商业用途吗？**
   - 介意 → 这两个都不完全禁止商业使用；如果确实要禁止，需要另选带 **NC**（非商业）的许可证，但本仓库不推荐，因为很多学校采购流程会因此卡住。

拿不准就选 **MIT**——它最简单，也最容易被学校接受。

## 五、具体怎么放：三步

### 第 1 步：在课件目录里放一个 `LICENSE` 文件

```
junior_high/optics/convex_lens/convex_lens_show(San_Zhang)/
├─ index.html
├─ README.md
├─ LICENSE        ← 这个文件
└─ assets/
```

文件内容就是许可证全文。**直接复制模板，改两处就行**：

- 年份：改成今年；
- 作者名：改成你的名字。

模板在 [CONTRIBUTING 第 5 节](../CONTRIBUTING.md) 里：5.1 是 MIT 全文，5.2 是 CC BY-SA 4.0 全文，复制即可。

### 第 2 步：在 `README.md` 里写一句版权说明

例如：

```text
- 版权说明：Copyright (c) 2026 张三。本课件采用 MIT 许可证，详见同目录 LICENSE 文件。
```

要求：**README 里写的许可证，必须和 LICENSE 文件里的一致**。写 MIT 就两边都 MIT。

### 第 3 步：检查一下

- [ ] 课件目录里有 `LICENSE` 文件
- [ ] 文件里改了年份和作者名
- [ ] `README.md` 里有一句版权说明
- [ ] 两处写的许可证类型一致

## 六、常见误解（老师问得最多的）

### 1. 放了许可证，版权是不是就送人了？

**不是。** 版权一直是你的。许可证只是你「允许别人怎么用」，不是「把作品送人」。

你可以随时停止授权新版本，但**已经按旧许可证拿到作品的人，他们的授权收不回来**。

### 2. 别人拿我的课件去卖钱，可以吗？

MIT 和 CC BY-SA 4.0 都**允许**商业使用（这也是它们被学校接受的原因）。如果你确实不希望，可以在 README 里说明，但这已经超出标准许可证的范围，建议先来 Issue 里讨论。

### 3. 学校内部上课用，也需要许可证吗？

严格说，课堂放映属于使用作品，有许可证最省心。更重要的是：**学校要统一采购、放到校内平台时，会查许可证。** 有 LICENSE 文件，流程才走得通。

### 4. 我用了教材上的插图，怎么办？

**不能直接用。** 教材插图版权属于出版社，不在你的授权范围内。请换成：

- 自己画的图；
- 明确标注可免费使用的素材（并写清来源）；
- 或者不用图，用文字/动画代替。

本仓库**不接受**来源不明的图片、音频，也不接受反编译自 Flash 课件的素材。

### 5. 我用 AI 生成的代码/图片，版权算谁的？

目前各国规定不一致，稳妥做法是：

- 在 README 里写清楚哪些部分用了 AI 辅助；
- 公式、方向、单位、文案由你本人逐项核对；
- 不要把 AI 生成的、疑似侵权的内容当成自己的原创素材。

### 6. 没有 LICENSE 文件会怎样？

别人默认「保留所有权利」，也就是**不能随便用**。对教学仓库来说，这等于让课件失去使用价值。

### 7. 我可以以后再改许可证吗？

可以，但只对**你之后发布的新版本**有效；别人已经按旧许可证获得的授权，不能收回。所以一开始就想清楚。

### 8. 学生做的作品可以放进来吗？

可以，但需要学生本人（未成年人还需监护人）同意，并由他们在课件目录里署名。

### 9. MIT 和「开源」是一回事吗？

不完全是。开源强调的是「源代码可获取、可修改」，许可证是法律上的授权方式。MIT 是开源许可证的一种，也是本仓库最推荐的一种。

---

## 七、这个仓库的具体要求

- 每个课件目录**必须**有 `LICENSE` 文件；
- 推荐 **MIT** 或 **CC BY-SA 4.0**；
- `README.md` 里要有版权说明，且和 LICENSE 一致；
- 不接受：来源不明的素材、教材插图、商业课件、反编译自 Flash 的内容；
- 仓库自身的索引、脚本、文档使用 MIT，见根目录 [LICENSE](../LICENSE)。

## 八、最后一句

许可证不是给律师看的，是给**下一个想用你课件的老师**看的。

写清楚一句话，别人就敢用；不写，再好的课件也只能躺在硬盘里。
